# Case: personal app (Sara)

A personal music-study app, used here as the simple, public example of the platform.

- **Shape:** a web frontend and a small API, each delivered as an independent workload.
- **Delivery:** exactly the same flow as the larger apps, which validates the pattern in a low-risk case.
- **Role:** acts as a demo app. It may get its own domain in the future.

It is the counterpoint to the [computer-vision case](computer-vision.md): same platform, very different scale
and risk.
