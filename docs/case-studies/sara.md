# Caso: app pessoal (Sara)

Um app pessoal de estudo musical, usado aqui como o exemplo público e simples da plataforma.

- **Forma:** frontend web e uma API pequena, cada um entregue como workload independente.
- **Entrega:** exatamente o mesmo fluxo dos apps maiores, o que valida o padrão num caso de baixo risco.
- **Papel:** serve de app de demonstração. Pode ganhar domínio próprio no futuro.

É o contraponto ao [caso de visão computacional](computer-vision.md): mesma plataforma, escala e risco muito
diferentes.
